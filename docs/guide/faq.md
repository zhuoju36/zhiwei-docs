# 常见问题

## 安装与部署

### Q：止危支持哪些部署方式？

A：目前推荐 Docker Compose 单机部署；生产环境可使用 Kubernetes 部署。源码运行方式参考 [开发环境](/developer/environment)。

### Q：最低硬件配置要求是什么？

A：对于测试与小规模项目，建议至少 2 核 CPU、4 GB 内存、50 GB 磁盘。生产环境根据传感器数量与采样频率扩展。

### Q：默认端口冲突怎么办？

A：修改 `docker-compose.yml` 或环境变量中的端口映射即可。

## 数据接入

### Q：支持哪些传感器品牌？

A：止危通过协议适配层接入设备，只要设备支持 MQTT、HTTP、Modbus 等标准协议或提供数据格式文档，即可接入。

### Q：如何接入自己的设备？

A：参考 [接入协议](/developer/protocol/) 了解标准数据格式，必要时开发自定义协议解析插件。

### Q：数据采样频率最高支持多少？

A：取决于存储与计算资源配置。常规结构监测场景支持 1 Hz–1 kHz；高频振动分析场景建议按需扩展时序数据库集群。

## 功能使用

### Q：一个测点可以绑定多个传感器吗？

A：可以。一个测点可绑定一个主传感器和多个辅助传感器，用于多方向或多物理量联合分析。

### Q：告警支持哪些通知方式？

A：当前支持页面内通知、邮件与 Webhook；短信与企业微信等可通过 Webhook 扩展。

### Q：能否导出历史数据？

A：支持。可在「数据查看」或「报表」页面选择时间范围与格式（CSV / Excel / JSON）导出。

## 开发与贡献

### Q：如何参与开发？

A：阅读 [贡献指南](/developer/contribute)，fork 仓库后提交 PR。

### Q：是否支持二次开发？

A：支持。止危提供 RESTful API 与插件机制，可在不修改核心代码的情况下扩展功能。
