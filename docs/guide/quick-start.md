# 快速开始

本指南将帮助你在 5 分钟内启动止危平台，并完成第一个结构物与测点的创建。

## 环境要求

- Docker Engine >= 24.0
- Docker Compose >= 2.20
- 浏览器（推荐 Chrome / Edge / Firefox 最新版）

> 如果你不想使用 Docker，也可以参考 [开发环境搭建](/developer/environment) 进行源码运行。

## 1. 获取代码

```bash
git clone https://github.com/zhiwei-shm/zhiwei.git
cd zhiwei
```

## 2. 启动服务

```bash
docker compose up -d
```

该命令会依次启动：

- 关系型数据库（PostgreSQL）
- 时序数据库（TimescaleDB / InfluxDB）
- 消息队列（MQTT Broker / Redis）
- 后端服务（shm-backend）
- 前端站点（shm-frontend）

## 3. 访问平台

打开浏览器，访问：

```
http://localhost:8080
```

默认管理员账号：

- 用户名：`admin`
- 密码：`admin`

> 首次登录后请立即修改默认密码。

## 4. 创建第一个结构物

1. 进入「项目管理」页面，点击「新建项目」，输入项目名称，例如「某跨江大桥健康监测」。
2. 在项目下创建「结构物」，选择类型为「桥梁」。
3. 在结构物下创建「测点」，例如「主跨 1/4 截面挠度测点」。
4. 为测点绑定「传感器」，选择传感器类型（如位移计）并填写通道号。

## 5. 模拟数据并查看

在「数据采集」页面，点击「模拟数据」，选择刚才创建的测点，设置采样频率与持续时间，点击「开始」。

稍等片刻后，进入「可视化看板」，即可看到实时曲线与特征值变化。

## 6. 配置告警

1. 进入「告警规则」页面，点击「新建规则」。
2. 选择测点与指标（如挠度最大值）。
3. 设置阈值条件（如 > 50 mm）。
4. 选择通知方式（页面内通知 / 邮件 / Webhook）。

当模拟数据触发阈值时，你将在告警中心看到对应事件。

## 常见问题

**Q：启动后端口被占用怎么办？**

A：修改 `docker-compose.yml` 中的端口映射，例如将 `8080:80` 改为 `8081:80`。

**Q：忘记管理员密码怎么办？**

A：在后端服务容器中执行重置命令，具体参考 [配置项说明](/deploy/config)。
