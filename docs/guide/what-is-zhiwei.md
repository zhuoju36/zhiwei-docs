# 什么是止危

**止危**（Zhiwei）是一个开源的结构健康监测（Structural Health Monitoring，SHM）平台，面向桥梁、建筑、风机、铁路等基础设施，提供从数据采集、存储、分析到可视化展示的一站式解决方案。

## 为什么做止危

传统的结构健康监测系统往往面临以下问题：

- **封闭**：软硬件绑定，扩展困难，数据难以导出
- **昂贵**：商业软件授权费用高，中小项目难以承受
- **复杂**：部署与配置门槛高，工程人员难以上手
- **孤岛**：采集、分析、可视化工具割裂，难以形成闭环

止危的目标是用开源、模块化、可扩展的方式，让每个工程团队都能低成本地搭建自己的监测平台。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 项目管理 | 项目-设备-传感器-通道四级组织，按项目隔离数据，普通用户需授权方可访问 |
| 数据接入 | 内置 MQTT、HTTP、Modbus TCP、DTU 透传（Modbus RTU over TCP）等适配器；新增协议 = 新增一个适配器文件 |
| 时序存储 | TimescaleDB hypertable，按通道粒度写入，单实例可达 10 万点/秒 |
| 实时计算 | 阈值告警、FFT 频谱、基础统计等插件，Celery 异步驱动 |
| 可视化 | 曲线、热力图、频谱、3D 模型联动（GLB 自动转换） |
| 告警通知 | 按通道配置告警规则，支持 Webhook、Email 多渠道并发派发 |
| 开放 API | RESTful API + Swagger UI + WebSocket 实时推送，方便二次开发 |

## 数据拓扑

```
用户 → 项目 → 设备 → 传感器（位置 + 仪器元数据）→ 通道（单位 / 采样率 / 告警规则）→ 读数
```

v0.9 起把测点与传感器合一——实际部署中一测点对应一个仪器，位置坐标与仪器元数据同行；单位、采样率、告警规则下放到通道，时序数据按通道存储与寻址。
