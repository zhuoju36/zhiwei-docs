# 什么是止危

**止危**（Zhiwei）是一个开源的结构健康监测（Structural Health Monitoring，SHM）平台，面向桥梁、建筑、风机、铁路等基础设施，提供从数据采集、存储、分析到可视化展示的一站式解决方案。

## 为什么做止危

传统的结构健康监测系统往往面临以下问题：

- **封闭**: 软硬件绑定，扩展困难，数据难以导出
- **昂贵**: 商业软件授权费用高，中小项目难以承受
- **复杂**: 部署与配置门槛高，工程人员难以上手
- **孤岛**: 采集、分析、可视化工具割裂，难以形成闭环

止危的目标是用开源、模块化、可扩展的方式，让每个工程团队都能低成本地搭建自己的监测平台。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 项目管理 | 按项目-结构物-测点-传感器四级组织监测对象 |
| 数据接入 | 支持 MQTT、HTTP、Modbus 等协议，提供标准化数据格式 |
| 实时处理 | 流式特征值计算、阈值告警、事件触发 |
| 数据存储 | 时序数据库长期存储高频采样数据 |
| 可视化 | 曲线、热力图、频谱、3D 模型联动 |
| 告警通知 | 规则引擎 + 多渠道通知（邮件、Webhook、短信） |
| 开放 API | RESTful API 与 OpenAPI 文档，方便二次开发 |

## 开源协议

止危采用 [MIT 协议](/about/license) 开源，可自由用于商业与非商业场景。
