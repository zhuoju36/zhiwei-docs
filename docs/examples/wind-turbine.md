# 风机监测案例

## 项目背景

某海上风电场需要对风机塔筒、基础与叶片进行结构健康监测，重点关注疲劳载荷与极端风况响应。

## 监测内容

| 监测项 | 传感器类型 | 通道数 | 单通道采样率 |
| --- | --- | --- | --- |
| 塔筒振动 | 加速度计（3 轴 IMU） | 36（12×3） | 100 Hz |
| 叶片应变 | 光纤应变计 | 36 | 50 Hz |
| 基础沉降 | GNSS / 静力水准 | 6 | 1 Hz |
| 风速风向 | 测风塔 | 4 | 1 Hz |

合计 82 个通道。

## 平台配置

1. 创建「海上风电场监测」项目
2. 为每台风机创建一个设备
3. 在设备下按塔筒、叶片、基础、风速仪分组创建传感器与通道
4. 关键告警规则示例（叶片应变）：

   ```json
   [
     {"operator": "gt", "threshold": 1500, "level": "warning",
      "message": "叶片应变超 1500 με"},
     {"operator": "gt", "threshold": 2200, "level": "danger",
      "message": "叶片应变临近疲劳极限"}
   ]
   ```

5. 利用 FFT 频谱分析（`POST /api/v1/analysis/jobs`）识别塔筒固有频率变化
6. 通过 Webhook 把告警推送回风电场 SCADA 系统

## 效果

- 预警塔筒异常振动与基础沉降
- 评估叶片疲劳损伤趋势
- 辅助制定检修计划
