# 风机监测案例

## 项目背景

某海上风电场需要对风机塔筒、基础与叶片进行结构健康监测，重点关注疲劳载荷与极端风况响应。

## 监测内容

| 监测项 | 传感器类型 | 数量 |
| --- | --- | --- |
| 塔筒振动 | 加速度计 | 12 |
| 叶片应变 | 光纤应变计 | 36 |
| 基础沉降 | GNSS / 静力水准 | 6 |
| 风速风向 | 测风塔 | 2 |

## 平台配置

1. 创建「海上风电场监测」项目
2. 为每台风机创建独立结构物
3. 配置叶片应变与塔筒振动告警
4. 利用频谱分析识别塔筒固有频率变化

## 效果

- 预警塔筒异常振动与基础沉降
- 评估叶片疲劳损伤趋势
- 辅助制定检修计划
