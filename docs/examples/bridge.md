# 桥梁监测案例

## 项目背景

某跨江大桥全长 2,800 米，主跨 600 米，需对挠度、应变、振动、索力与交通荷载进行长期监测。

## 监测内容

| 监测项 | 传感器类型 | 数量 |
| --- | --- | --- |
| 挠度 | GPS 位移计、静力水准仪 | 12 |
| 应变 | 振弦式应变计 | 48 |
| 振动 | 加速度计 | 24 |
| 索力 | 振弦式索力计 | 16 |
| 环境 | 温湿度计、风速仪 | 8 |

## 网络拓扑

```
传感器 → 数据采集仪 → 4G 路由器 → MQTT Broker → 止危平台
```

## 平台配置

1. 创建「某跨江大桥健康监测」项目
2. 创建「主桥」结构物，按主跨、边跨、桥塔组织测点
3. 批量导入传感器与通道信息
4. 配置挠度、应变、振动阈值告警规则
5. 创建可视化看板，展示关键截面实时状态

## 效果

- 实时掌握桥梁在车辆、风载作用下的响应
- 台风、重车通行期间自动触发告警
- 定期生成运营期健康评估报告
