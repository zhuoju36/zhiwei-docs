# 桥梁监测案例

## 项目背景

某跨江大桥全长 2,800 米，主跨 600 米，需对挠度、应变、振动、索力与交通荷载进行长期监测。

## 监测内容

| 监测项 | 传感器类型 | 通道数 | 单通道采样率 |
| --- | --- | --- | --- |
| 挠度 | GPS 位移计、静力水准仪 | 12 | 1 Hz |
| 应变 | 振弦式应变计 | 48 | 1 Hz |
| 振动 | 加速度计（3 轴 IMU） | 72（24×3） | 100 Hz |
| 索力 | 振弦式索力计 | 16 | 1 Hz |
| 环境 | 温湿度计、风速仪 | 8 | 0.2 Hz |

合计 156 个通道，按 v0.9 拓扑建模：项目下挂多个设备（按桥段分组），每个传感器挂 1–3 个通道。

## 网络拓扑

```
传感器 ──采集网关（多协议）──4G 路由器──边缘网关（Python 适配器）
                                          │
                                          ▼
                                    POST /api/v1/data/ingest
                                    （X-API-Key，按通道批量上报）
                                          │
                                          ▼
                                   止危后端 + Redis Pub/Sub
                                          │
                                          ▼
                                   WebSocket 实时推送到前端
```

## 平台配置

1. 创建「某跨江大桥健康监测」项目，配置位置（lat/lng/address）
2. 按桥段创建多个设备（主跨 / 边跨 / 桥塔）
3. 在设备下创建传感器（位置 + 仪器元数据：型号、厂商、校准日期）
4. 为每台 3 轴 IMU 创建 X / Y / Z 三个通道，分别配置 `unit`、`sampling_rate=100`、`alert_rules`
5. 单通道阈值告警规则示例（X 轴加速度）：

   ```json
   {
     "operator": "gt",
     "threshold": 0.5,
     "level": "warning",
     "message": "X 轴加速度超 0.5 m/s²",
     "suppress_seconds": 60
   }
   ```

6. 上传桥的 GLB 模型，配置 3D 大屏测点联动
7. 创建可视化看板：关键截面的实时曲线 + 频谱 + 告警面板

## 效果

- 实时掌握桥梁在车辆、风载作用下的响应
- 台风、重车通行期间自动触发告警并通过 Webhook / Email 通知
- 利用 FFT 频谱分析识别模态频率变化
- 定期生成运营期健康评估报告
