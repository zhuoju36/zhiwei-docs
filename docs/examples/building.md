# 建筑监测案例

## 项目背景

某超高层办公楼高度 320 米，施工阶段与运营阶段均需监测结构沉降、倾斜、振动与风压。

## 监测内容

| 监测项 | 传感器类型 | 数量 |
| --- | --- | --- |
| 沉降 | 静力水准仪 | 20 |
| 倾斜 | 倾角仪 | 12 |
| 振动 | 加速度计 | 16 |
| 风压 | 风压计 | 8 |
| 温度 | 温度计 | 24 |

## 平台配置

1. 创建项目与「主楼」结构物
2. 按楼层与核心筒分区创建测点
3. 配置沉降速率与倾斜角度告警
4. 建立日报模板，自动推送施工方

## 效果

- 施工阶段实时预警不均匀沉降
- 运营阶段评估风振舒适度
- 为结构安全评定提供长期数据支撑
