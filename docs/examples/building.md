# 建筑监测案例

## 项目背景

某超高层办公楼高度 320 米，施工阶段与运营阶段均需监测结构沉降、倾斜、振动与风压。

## 监测内容

| 监测项 | 传感器类型 | 通道数 | 单通道采样率 |
| --- | --- | --- | --- |
| 沉降 | 静力水准仪 | 20 | 0.1 Hz |
| 倾斜 | 倾角仪（双轴） | 24（12×2） | 1 Hz |
| 振动 | 加速度计（3 轴 IMU） | 48（16×3） | 100 Hz |
| 风压 | 风压计 | 8 | 10 Hz |
| 温度 | 温度计 | 24 | 0.1 Hz |

合计 124 个通道。

## 平台配置

1. 创建项目，配置经纬度与地址
2. 按楼层与核心筒分区创建设备，每台设备对应一个采集网关
3. 在设备下创建传感器（带 `position` 三维坐标），便于 3D 大屏联动
4. 沉降类通道使用 `channel_type="displacement"`，单位 `mm`；倾斜类用双轴通道 `X` / `Y`
5. 配置关键告警：

   ```json
   [
     {"operator": "gt", "threshold": 0.05, "level": "warning",
      "message": "沉降速率超 0.05 mm/天"},
     {"operator": "gt", "threshold": 0.3,  "level": "danger",
      "message": "累计沉降超 30 mm"}
   ]
   ```

6. 上传楼的 GLB 模型（OBJ / STL / PLY / glTF / GLB 自动转换 GLB）
7. 启用 Webhook 通知通道（钉钉 / 企微 / Slack 都可通过 Webhook 适配）

## 效果

- 施工阶段实时预警不均匀沉降
- 运营阶段评估风振舒适度
- 为结构安全评定提供长期数据支撑
- 报警自动派发到施工 / 运维方
