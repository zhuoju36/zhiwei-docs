# 铁路/轨道监测案例

## 项目背景

某高速铁路沿线需要对桥梁、路基、隧道口进行长期监测，确保运营安全。

## 监测内容

| 监测项 | 传感器类型 | 通道数 | 单通道采样率 |
| --- | --- | --- | --- |
| 轨温 | 温度传感器 | 50 | 0.1 Hz |
| 轨缝 | 位移传感器 | 30 | 10 Hz |
| 道床沉降 | 静力水准仪 | 20 | 0.1 Hz |
| 桥梁挠度 | 位移计 | 16 | 10 Hz |
| 车辆荷载 | 应变计 | 40 | 100 Hz |

合计 156 个通道。

## 平台配置

1. 创建「高速铁路沿线监测」项目
2. 按线路里程创建多个设备，每个设备接入一路采集网关（DTU 透传 / MQTT / Modbus TCP 任意）
3. 在设备下创建传感器与通道
4. 关键告警规则示例（轨缝位移）：

   ```json
   {
     "operator": "gt",
     "threshold": 18,
     "level": "warning",
     "message": "轨缝超 18 mm",
     "suppress_seconds": 300
   }
   ```

5. 通过 `POST /api/v1/analysis/jobs` 提交 FFT 分析任务，按需评估桥梁挠度频谱
6. 对接运维调度系统：通过 Webhook 把告警推送过去，或在前端用 `GET /api/v1/data/timeseries` 反向喂数据

## 效果

- 实时掌握轨道几何状态变化
- 高温季节提前预警轨缝异常
- 为线路养护维修提供数据依据
