# 核心团队

止危由一群热爱开源与工程技术的开发者共同维护。

## 维护者

| 角色 | 职责 | 联系方式 |
| --- | --- | --- |
| 项目负责人 | 项目整体规划与架构设计 | - |
| 前端负责人 | 前端开发与可视化 | - |
| 后端负责人 | 后端服务与数据处理 | - |
| 文档负责人 | 文档维护与社区运营 | - |

## 如何加入

如果你对结构健康监测、物联网、可视化或开源社区运营感兴趣，欢迎通过 [联系我们](/community/contact) 加入团队。
