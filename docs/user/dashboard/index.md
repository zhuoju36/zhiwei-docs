# 可视化看板

可视化看板用于将监测数据、告警状态与结构模型进行直观展示。

## 功能概述

- 支持 2D/3D 结构模型与测点联动
- 支持多种图表类型（时序曲线、散点图、热力图、频谱图）
- 支持自定义布局与全屏展示
- 支持大屏模式，适用于监控中心

## 操作步骤

### 创建看板

1. 进入「可视化看板」页面
2. 点击「新建看板」
3. 选择结构物与模板
4. 添加图表组件并绑定测点
5. 调整布局后保存

### 配置 3D 模型

1. 在结构物管理中上传模型文件
2. 在看板编辑模式下将测点拖拽到模型对应位置
3. 保存关联关系

### 全屏展示

1. 打开目标看板
2. 点击右上角「全屏」按钮
3. 按 `Esc` 退出全屏
