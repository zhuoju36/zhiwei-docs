# 传感器与通道

传感器是实际采集数据的硬件设备，通道是传感器上的独立数据输入。

## 功能概述

- 管理传感器基础信息（型号、厂商、编号、安装日期）
- 配置传感器通道与量程、单位、采样参数
- 将通道绑定到具体测点
- 管理传感器校准记录

## 操作步骤

### 添加传感器

1. 进入「传感器管理」页面
2. 点击「新建传感器」
3. 选择传感器类型（振弦、应变、加速度、位移、温湿度等）
4. 填写型号、序列号、厂商信息
5. 配置通道数量与每个通道的参数
6. 保存

### 绑定通道到测点

1. 在传感器详情页选择目标通道
2. 点击「绑定测点」
3. 选择要绑定的测点
4. 确认绑定关系

### 校准管理

1. 进入传感器详情页
2. 点击「校准记录」
3. 添加上次校准日期、校准系数、校准报告附件
