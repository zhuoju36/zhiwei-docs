# 项目管理

项目是止危中的顶级管理单元，用于组织结构物、用户、权限与配置。

## 功能概述

通过项目管理，你可以：

- 创建与管理多个监测项目
- 为项目分配成员与角色
- 配置项目级参数（时区、数据保留策略等）
- 查看项目总体统计与告警概览

## 操作步骤

### 创建项目

1. 进入「项目管理」页面
2. 点击「新建项目」
3. 填写项目名称、描述与负责人
4. 点击「保存」

### 编辑项目

1. 在项目列表中选择目标项目
2. 点击「编辑」
3. 修改信息后保存

### 删除项目

> 删除项目将级联删除其下所有结构物、测点与数据，请谨慎操作。

1. 在项目列表中选择目标项目
2. 点击「删除」
3. 输入确认信息后确认删除
