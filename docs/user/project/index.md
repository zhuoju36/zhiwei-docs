# 项目管理

项目是止危中的顶级管理单元与数据隔离边界。每个项目独立管理设备、传感器、通道、用户授权、3D 模型与告警事件。

## 功能概述

通过项目管理，你可以：

- 创建与管理多个监测项目
- 为项目分配成员并按角色授权（admin / write / read）
- 配置项目级参数（位置坐标等）
- 查看项目总体统计、活跃告警与最近事件
- 上传并管理项目对应的 3D 模型

## 操作步骤

### 创建项目

1. 进入「项目管理」页面
2. 点击「新建项目」
3. 填写项目名称、描述、可选的位置（经纬度 / 地址）
4. 点击「保存」

> 只有 `admin` 角色可以创建项目。

### 编辑项目

1. 在项目列表中选择目标项目
2. 点击「编辑」
3. 修改信息后保存（字段可选，按 PATCH 语义更新）

### 删除项目

> 删除项目将级联删除其下所有设备、传感器、通道、读数、3D 模型、授权记录——操作不可逆，请谨慎。

1. 在项目列表中选择目标项目
2. 点击「删除」
3. 输入确认信息后确认删除

### 成员授权

1. 进入项目详情
2. 切换到「成员管理」标签
3. 添加用户 ID 并指定权限级别（`read` / `write` / `admin`）
4. 保存

权限矩阵：

| 操作 | 项目 admin | 项目 write | 项目 read |
| --- | --- | --- | --- |
| 查看设备 / 传感器 / 通道 | ✓ | ✓ | ✓ |
| 查看实时数据与历史数据 | ✓ | ✓ | ✓ |
| 创建 / 修改设备、传感器、通道 | ✓ | ✓ | ✗ |
| 删除设备、传感器、通道 | ✓ | ✗ | ✗ |
| 上传 3D 模型 | ✓ | ✓ | ✗ |
| 确认告警 | ✓ | ✗ | ✗ |
| 授权 / 撤销成员 | ✓ | ✗ | ✗ |

## API 入口

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/v1/projects` | `GET` | 分页列出可见项目 |
| `/api/v1/projects` | `POST` | 创建项目（admin） |
| `/api/v1/projects/{id}` | `GET / PUT / DELETE` | 详情 / 更新 / 删除 |
| `/api/v1/projects/{id}/users` | `POST` | 授权或更新用户权限 |

详见 [接口文档 - 项目](/developer/api/#项目)。
