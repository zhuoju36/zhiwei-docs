# 报表与导出

报表模块用于定期汇总监测数据、告警事件与设备状态，生成可分享的报告。

## 功能概述

- 自定义报表模板（日报、周报、月报）
- 支持包含曲线、统计表、告警列表等内容
- 支持定时生成与邮件推送
- 支持导出为 PDF、Word、Excel

## 操作步骤

### 创建报表模板

1. 进入「报表中心」
2. 点击「新建模板」
3. 选择报表类型与周期
4. 拖拽添加需要展示的内容块
5. 保存模板

### 生成报表

1. 选择报表模板
2. 设置时间范围
3. 点击「生成报表」
4. 预览后导出或分享

### 定时任务

1. 在模板设置中开启「定时生成」
2. 设置生成周期与推送邮箱
3. 保存
