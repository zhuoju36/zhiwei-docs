# 告警规则

告警规则用于在监测数据异常时自动触发通知与记录事件。

## 功能概述

- 基于特征值或原始值设置阈值条件
- 支持多级告警（提示 / 一般 / 严重 / 紧急）
- 支持告警抑制、延时触发与恢复通知
- 支持页面内通知、邮件、Webhook 等通知渠道

## 操作步骤

### 创建告警规则

1. 进入「告警规则」页面
2. 点击「新建规则」
3. 选择规则作用范围（项目 / 结构物 / 测点）
4. 选择指标（最大值、最小值、均值、峰峰值等）
5. 设置条件（>、<、=、范围内、范围外）与阈值
6. 配置告警等级与通知方式
7. 保存并启用

### 查看告警事件

1. 进入「告警中心」
2. 可按时间、等级、状态（未处理 / 处理中 / 已恢复）筛选
3. 点击事件可查看详情与处理记录

### 处理告警

1. 在告警详情页点击「处理」
2. 填写处理人与处理说明
3. 标记为已处理或恢复
