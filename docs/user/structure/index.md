# 结构物与测点

结构物是被监测的物理对象，测点是结构物上具体的监测位置。

## 功能概述

- 结构物支持桥梁、建筑、风机、隧道、铁路等类型
- 测点支持多层级组织，例如按构件、截面、方向分组
- 支持将测点与结构模型（2D/3D）关联，实现数字孪生展示

## 操作步骤

### 创建结构物

1. 在项目下进入「结构物管理」
2. 点击「新建结构物」
3. 选择结构物类型，填写名称、位置、设计参数
4. 上传结构图纸或 3D 模型（可选）
5. 保存

### 创建测点

1. 进入目标结构物详情页
2. 点击「新建测点」
3. 填写测点名称、位置描述、坐标信息
4. 选择测点监测类型（挠度、应变、振动、温度等）
5. 保存

### 绑定传感器

测点创建后，可在「传感器与通道」页面为测点绑定传感器。
